# 컷 비주얼이 들어올 자리

아직 비어 있다. 지난 안(천지창조)의 컷 이미지는 컨셉이 달라 전부 지웠다 —
남겨 두면 도미노 씬에 엉뚱한 그림이 붙는다.

들어와야 할 여덟 장. 전부 **밝고 화사한 실사형**이고, **로고는 반드시 레이어를 분리**한다
(구워 넣으면 재사용 포맷이 무너진다).

흐름은 **앞 → 안쪽 → 다시 바깥**이다. 무대 가운데에서 시작한 쓰러짐이 화면 아래로
들어가 원근을 타고 멀어지고, 길 끝 오브제에서 빛이 되어 돌아 나온다.
**로고는 마지막 한 장에만** 들어간다.

| 파일 | 무엇 | 공통 / 갈림 |
|---|---|---|
| `cut1-a.jpg` | CUT 01 · **1안** — 무대 실물 도미노와 이어지는 화면 아래 끝단 | 인트로 |
| `cut1-b.jpg` | CUT 01 · **2안** — 화면 안에서 첫 장이 넘어간다 | 인트로 |
| `cut2.jpg` | CUT 02 — 마을의 길을 따라 안쪽으로 번져 간다 | **공통** |
| `cut3-t.jpg` | CUT 03 · ㉠ 온도계 — 눈금이 차오른다 | 오브제 |
| `cut3-r.jpg` | CUT 03 · ㉡ 나무 — 뿌리에 닿아 줄기가 오른다 | 오브제 |
| `cut4-t.jpg` | **CUT 04 · ㉠ — 가득 차 넘치며 마을이 밝아진다** | 오브제 |
| `cut4-r.jpg` | **CUT 04 · ㉡ — 가지가 뻗어 마을을 덮는다** | 오브제 |
| `cut5-t.jpg` | CUT 05 · ㉠ — 좌 · 우 로고 등장 (로고 자리는 비워 둔다) | 오브제 |
| `cut5-r.jpg` | CUT 05 · ㉡ — 좌 · 우 로고 등장 (로고 자리는 비워 둔다) | 오브제 |

**CUT 04 두 장이 가장 공들일 곳이다** — 이 덱에서 가장 오래 머무는 컷이고,
앞을 빠르게 지나온 이유가 전부 거기 있다.

파일이 들어오면 `js/storyboard.js` 의 `CUTS` 와 `js/object.js` 의 `OBJ` 에 `img` 를 채운다. 지금은 `img` 가 없어 이름만 든 판으로 그려지고 있고, 레이아웃은 그대로다.
