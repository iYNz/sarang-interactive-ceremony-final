## 모든 요청문에 공통으로 붙일 것

지난 시안이 「비주얼은 사실적이어서 좋았으나 겨울톤이라 너무 어두웠다」는 평을
받았다. 그 한 줄이 이번 톤의 전부다 — **사실감은 유지하고 밝기만 뒤집는다.**

```
■ 공통 조건 (모든 컷에 적용)

- 사실적인 3D 렌더. 일러스트나 플랫 스타일이 아니다.
- 밝고 화사한 톤. 따뜻한 낮빛에서 시작해 장면이 진행될수록 색이 차오른다.
  어두워졌다 밝아지는 것이 아니라, 밝은 데서 더 화사해지는 변화다.
- 첨부한 ref-tone-snowball.jpg 는 "질감은 이렇게, 밝기는 정반대로" 의 예시다.
  겨울밤 · 남색 · 차가운 빛은 쓰지 않는다.
- 로고와 문자는 넣지 않는다. 한글이든 영문이든 글자가 보이면 안 된다.
- 16:9 / 1920×1080.
```

**로고를 절대 굽지 않는다**가 이 중 가장 중요하다. 로고는 CUT 05 에서 CMS 가 얹는
레이어이고, 그림 안에 들어가면 기업이 바뀔 때마다 다시 뽑아야 한다.

## A. 03p — 무대 두 장

같은 장소, 같은 사람, 같은 각도. **다른 것은 무대에 실물이 있느냐 하나뿐**이어야
두 장을 나란히 놓았을 때 차이가 보인다. 그래서 두 장 다 `base-stage.jpg` 를 바탕으로
편집시킨다 — 각각 따로 생성하면 장소가 미묘하게 달라진다.

### A-1 · 1안 (실물 도미노 + LED) → `stage-plan-a.jpg`

> **트리거** : `base-stage.jpg`, `guide-stage-layout.jpg`, `ref-domino.jpg`

```
첨부한 base-stage.jpg 의 공간을 그대로 두고, 무대 바닥에만 요소를 더해 주세요.

guide-stage-layout.jpg 는 배치 지정도입니다. 파란 실루엣은 사람의 자리와 키,
빨간 사각형은 도미노의 자리와 크기입니다. 이 선 자체는 그리지 마시고,
그 위치와 크기에 실제 사물을 놓아 주세요.

- 정장 차림의 성인 남성 두 명이 파란 실루엣 자리에 서 있습니다. 화면(정면)을
  바라보며 나란히, 안쪽으로 살짝 몸을 기울여 가운데의 도미노에 손을 뻗습니다.
- 두 사람 사이 바닥에 흰색 도미노 4장이 세워져 있습니다. 카메라에서 LED 화면
  쪽으로 한 줄(종으로)이고, 뒤로 갈수록 원근에 따라 작아집니다.
  높이는 성인 남성의 가슴과 배꼽 사이 — 키의 약 65% 입니다.
  형태와 재질은 ref-domino.jpg 를 따릅니다. 매트한 흰색, 모서리는 살짝 둥글게.
- 도미노는 전부 서 있습니다. 쓰러지거나 기울어진 것은 없습니다.
- LED 화면은 검은 채로 비워 둡니다.
- 바닥 반사와 그림자는 원래 사진의 조명 방향을 따릅니다.
```

### A-2 · 2안 (LED 단독) → `stage-plan-b.jpg`

> **트리거** : `stage-plan-a.jpg`(A-1 결과), `base-stage.jpg`

A-1 의 결과를 트리거로 쓰는 것이 핵심이다. 사람을 새로 그리게 하면 두 장의 인물이
달라져 「같은 장면, 시작만 다름」이 무너진다.

```
첨부한 stage-plan-a.jpg 에서 두 가지만 바꿔 주세요. 나머지는 픽셀 단위로 같아야
합니다 — 공간, 조명, 두 사람의 모습과 자세, 카메라 각도 전부 그대로입니다.

1. 바닥의 흰색 도미노 4장을 지우고, 그 자리를 원래 바닥으로 되돌립니다.
   그림자와 반사도 함께 지웁니다. 무대에는 아무것도 놓여 있지 않습니다.

2. 검은 LED 화면 안에, 같은 도미노 4장이 화면 속 장면으로 그려집니다.
   화면 안쪽으로 이어지는 길 위에 한 줄로 서 있고, 화면 자체의 원근을 따라
   뒤로 갈수록 작아집니다. 화면 속 장면은 밝고 화사한 낮빛입니다.
   LED 발광이므로 주변 벽과 바닥에 은은한 빛 번짐이 생깁니다.

두 사람은 여전히 가운데 도미노를 향해 손을 뻗고 있습니다 — 이제 그 대상이
바닥이 아니라 화면 속에 있습니다.
```

## B. 컷 비주얼 — LED 화면 안에 들어갈 아홉 장

이쪽은 **화면 콘텐츠만** 만든다. 목업은 덱이 합성하므로 행사장은 그리지 않는다.
결과는 `assets/led/` 로 옮긴다.

흐름은 **앞 → 안쪽 → 다시 바깥**이다. 가운데에서 시작한 쓰러짐이 마을의 길을 타고
멀어지고, 길 끝 오브제에서 빛이 되어 돌아 나온다. **이 방향이 아홉 장을 관통한다.**

### 세계관을 먼저 한 장으로 고정한다 — `world.jpg`

컷마다 따로 만들면 마을이 매번 달라진다. **마을을 먼저 확정하고 그 한 장을 모든
컷의 트리거로 돌려 쓴다.**

> **트리거** : `ref-tone-snowball.jpg`

```
따뜻한 낮빛의 작은 마을을 위에서 비스듬히 내려다본 3D 렌더입니다.
가운데로 곧게 난 길이 화면 안쪽(지평선 쪽)으로 이어지고, 길 양옆으로 낮은
집들이 줄지어 있습니다. 집들은 아직 불이 꺼져 있습니다.
길 끝, 화면 가운데 안쪽에 빈 공터가 있습니다 — 여기에 나중에 오브제가 섭니다.

- 사실적인 3D. 미니어처 디오라마 같은 질감이되 장난감처럼 보이지는 않습니다.
- 밝고 화사한 낮. 크림빛 벽, 부드러운 파스텔 지붕, 맑은 하늘.
- 첨부 이미지는 질감 참고용입니다. 밝기와 색온도는 정반대로 가 주세요 —
  겨울밤이 아니라 환한 낮입니다.
- 글자와 로고는 넣지 않습니다.
```

### 아홉 장

`world.jpg` 를 매번 트리거로 붙이고, 그 위에서 무엇이 달라지는지만 적는다.

| 파일 | 요청문의 핵심 |
|---|---|
| `cut1-a.jpg` | 화면 **아래 가장자리**에서 흰 도미노 한 장이 안쪽으로 넘어가기 시작한다. 무대의 실물과 이어지는 지점이라 **화면 맨 아래에 붙어** 있어야 한다 |
| `cut1-b.jpg` | 같은 장면이되 도미노 줄이 **화면 안쪽에서** 시작한다. 아래 가장자리가 비어 있다 |
| `cut2.jpg` | 도미노가 **길을 따라 안쪽으로** 연쇄로 쓰러진다. 지나간 자리의 집들만 창에 불이 들어와 있다 — 쓰러짐이 곧 켜짐이다 |
| `cut3-t.jpg` | 길 끝 공터에 **온도계**가 서 있고 눈금이 아래에서 차오른다. 아직 마을은 반쯤 어둡다 |
| `cut3-r.jpg` | 같은 자리에 **나무**가 서 있고 뿌리에서 줄기가 올라온다 |
| `cut4-t.jpg` | **온도계가 가득 차 넘치며** 빛이 바깥으로 퍼진다. 마을 전체가 한 번에 밝아진다 |
| `cut4-r.jpg` | **가지가 사방으로 뻗어** 마을을 덮고, 가지 끝마다 열매가 열려 빛난다 |
| `cut5-t.jpg` | 밝아진 마을 전경. **좌 · 우 상단이 비어 있다** — 로고가 들어갈 자리 |
| `cut5-r.jpg` | 같은 전경, 나무 버전. 역시 좌 · 우 상단을 비운다 |

### 오브제 두 안의 요청문

**㉠ 온도계** — 트리거에 `ref-tower-1.jpg` · `ref-tower-2.png` 를 붙이되 이렇게 못 박는다.

```
첨부한 온도탑 사진은 기호의 출처일 뿐입니다. 그 조형을 그대로 세우지 마세요.
가져올 것은 두 가지 — 세로로 선 온도계의 눈금, 그리고 붉은 열매 세 알의 형태입니다.
별 모양 받침이나 사진 속 구조는 쓰지 않습니다. 매년 조형이 바뀌어도 그대로 쓸 수
있어야 하므로, 특정 연도의 탑이 아니라 온도계라는 기호로 보여야 합니다.
```

**㉡ 나무** — 트리거에 `ref-fruit-symbol.png` 를 붙인다.

```
가지 끝에 열리는 열매는 첨부한 심벌의 붉은 열매 세 알 형태를 따릅니다.
심벌 자체(로고)를 그리지는 마세요 — 열매의 모양과 색만 가져옵니다.
```

## 만드는 순서

1. **`world.jpg` 먼저.** 이게 흔들리면 아홉 장이 전부 흔들린다. 마음에 들 때까지
   여기서 반복한다.
2. **`cut4-t` · `cut4-r`.** 덱에서 가장 오래 머무는 컷이고, 앞을 빠르게 지나온
   이유가 전부 여기 있다. 이 두 장이 되면 나머지는 그 앞뒤를 채우는 일이다.
3. 나머지 일곱 장.
4. **03p 무대 두 장은 마지막.** A-2 가 A-1 결과에 물려 있으므로 A-1 을 먼저 확정한다.
