# 컷 비주얼이 들어올 자리

아직 비어 있다. 지난 안(천지창조)의 컷 이미지는 컨셉이 달라 전부 지웠다 —
남겨 두면 도미노 씬에 엉뚱한 그림이 붙는다.

들어와야 할 여덟 장. 전부 **밝고 화사한 실사형**이고, **로고는 반드시 레이어를 분리**한다
(구워 넣으면 재사용 포맷이 무너진다).

| 파일 | 무엇 |
|---|---|
| `intro.jpg` | 도입 — 좌 · 우 로고가 떠 있는 판 (로고 자리는 비워 둔다) |
| `cut1-a.jpg` | CUT 01 · 1안 — 실물 도미노와 이어지는 화면 끝단 |
| `cut1-b.jpg` | CUT 01 · 2안 — 화면 안에서 첫 장이 넘어간다 |
| `cut2.jpg` | CUT 02 — 마을의 길을 따라 번져 간다 |
| `cut3-a.jpg` | CUT 03 · ㉠ 온도계 + 열매, 온도 상승 |
| `cut3-b.jpg` | CUT 03 · ㉡ 화합 오브제 |
| `cut4.jpg` | **CUT 04 — 마을 전체가 밝아진 순간.** 가장 공들일 한 장 |
| `cut5.jpg` | CUT 05 — 좌 · 우 로고 등장 (로고 자리는 비워 둔다) |

파일이 들어오면 `js/storyboard.js` 의 `CUTS` 와 `js/object.js` 의 `OBJ` 에 `img` 를
채운다. 지금은 `img` 가 없어 이름만 든 판으로 그려지고 있고, 레이아웃은 그대로다.
